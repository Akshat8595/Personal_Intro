# Personal Intro Python Project

## Overview
This is a beginner-friendly Python project built over 5 days. It progressively enhances a simple script from printing "Hello World" to collecting and displaying user information in a structured format.

---

## Features
- Prints a basic "Hello, World!" message
- Takes user input (name, age, city, hobby)
- Displays a personalized welcome message
- Formats user data in a clean and readable way
- Well-commented final version for clarity

---

## Tech Stack
- Python 3
